- **Team Death Match** — Engage in thrilling battles where two teams compete against each other using all available weapons.
- **Death Match** — A free-for-all mode where players fight to be the last one standing, with access to all weapons and the option to play against bots.
- **Capture the Flag** — A classic mode where players must capture the enemy's flag while defending their own, requiring speed and strategy to succeed.
- **Survivor** — Similar to Death Match, but players do not respawn immediately, adding a layer of challenge to each round.
- **Pistol Frenzy** — A unique mode focusing on battles with pistols, grenades, or knives, emphasizing skill and precision.

- **One Shot One Kill** — A high-stakes mode where players start with only one hit point, requiring careful strategy and precision.
- **One Shot One Kill (Death Match)** — Similar to the previous mode, but played in teams, ideal for larger groups.
